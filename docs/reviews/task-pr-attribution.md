# 작업·PR별 귀속 — 자체 리뷰

판정: 표준 W1. 브랜치 codex/task-pr-attribution, 구현 기준 416181d, 최신 main e59db42 위의 e5f7b1f를 최종 확인. 구현과 같은 세션의 검토이며 독립 리뷰로 주장하지 않는다.

## 1. 읽기 범위
AGENTS.md 1~8장, contributing 판정·검증, metrics README, summary/collect의 누적 집계, #141 binding history·PR #142의 범위.
변경 단위: attribution.py, summary 및 CLI, manifest, 설치 복사본, PR 작성 템플릿, 문서, 회귀 검사.

## 2. 테스트 실효성
- 명시적 작업/PR 선택이 세션 시작 브랜치를 무시하는지 설치형 CLI와 키트 출력 대조.
- 같은 세션 A→B 전환에서 앞 누적값을 B에 몰아주지 않는지 검사. 경계 토큰은 두 PR 모두에 임의 배분하지 않음.
- 부모/자식·중복 기록·겹친 연결·연결 전 원천·부분 원천·관측되지 않은 연결 세션 검사.
- #141 이력 읽기·동일 연결 복사본·시간대 동등성·원본 불변·잘못된 PR 재연결·손상 파일 원자적 보존 검사.
- 기존 요약·Codex 원천·설치·매니페스트 관련 50개 통과. 최종 귀속 검사 15개 통과.

## 3. 발견 및 반영
| ID | 발견 | 반영 |
| --- | --- | --- |

## 4. 조건부 관점
동시성 열림: 저장소 공통 상태의 read/modify/write를 기존 파일 잠금과 임시 파일 원자 교체로 보호한다.
인가 닫힘: 네트워크·새 인증·원격 PR 쓰기 없음. 식별자·PR 번호·시각 검증, 파일 크기 제한, 손상 원천 fail-closed.

## 5. 정합성
- 기존 무연결 브랜치 요약은 유지. 연결을 사용한 저장소에서는 범위 없는 기본 요약을 막고 명시적 --branch로만 참고 집계.
- 기존 agent 본문 필드·라벨 유지. 정상 범위는 귀속 범위 주석을 추가하며 미확정은 비용/토큰 수치를 출력하지 않음.
- 누적 차 계산은 범위 필터 이전에 수행. 작업 경계 전 활동 시간을 뒤 작업으로 넘기지 않음.
- #140 수집 계약·#141 파일·기존 PR #143 본문·실제 연결 상태는 이번 구현 검증에서 수정하지 않음.
- 사용자 지침·PR 템플릿은 원본에서 생성했으며 설치본을 수동 수정하지 않음.

## 6. 검증과 한계
- 관련 50개 및 최종 귀속 15개 통과. 설치·키트 출력 일치, 원본/설치본 byte 일치, check --self 19개 일치, diff --check 통과.
- 전체 검사는 시도했으나 실행 환경에서 종료 코드 -1로 끝나 최종 결과를 얻지 못함. 완료/통과로 보고하지 않는다.
- 저장소 상태·미커밋 변경 점검. 새 모듈·문서와 식별자·시각만 추가했으며 Secret 패턴 점검 통과.
- 아직 실제 사용자 세션을 소급 바인딩하거나 프로젝트에 배포하지 않았다. 과거 혼합 기록을 임의 복원하지 않는다.
- #141과 summary/CLI/manifest/템플릿 경로가 겹치므로 병합 순서가 정해지면 통합 확인이 필요하다.
- 사용자 추가 요청에 따라 구현 커밋 e5f7b1f를 Push했다. 최신 origin/main과 충돌이 없고 생성 파일 19개가 일치한다. PR 생성 시 이 최종 리뷰를 함께 커밋한다.
