# #141 실행 근거 수집 — 최종 리뷰

2026-10-21. 구현과 분리한 R1·R2 세션에서 기본 수집과 업무 흐름 확장을 각각 독립 검토했다. 발견 사항 9건을 반영했다.

## 1. 읽기 범위
수집·전송 모듈, 설치 manifest·hooks·CLI, Grafana 대시보드와 운영 안내를 검토했다. 기준은 AGENTS 2·3·5·6, 기존 hooks 계약, ADR-0026과 AgentOps runbook이다.

## 2. 테스트 실효성
신규 모듈의 작업 연결·시간 경계·실패 격리·검증 실행·전송·업무 흐름 회귀를 검사한다. 기존 hooks 보존과 agent_records 호환성을 별도로 확인한다. 기존 차단 계약을 약화하지 않았다.

## 3. 발견 사항
아래 처리표의 U1~U4와 W1~W4를 모두 반영했다. 원문 제외, 인증 리다이렉트 차단과 직접 관측 출처 구분도 확인했다.

## 4. 공격 시도 기록
작업 전환 전 지연 수집, 연결 전 로그, 잘못된 중첩 메타데이터, 전송 실패·부분 거절, 리뷰 상태 복귀, 손상 등록부와 잘못된 답변 항목을 검토했다.

## 5. 단위 간 정합성
기존 토큰·비용 원천과 보호 hooks를 유지한다. 검사 조건의 성공을 작업 전체 완료로 해석하지 않으며 일반 답변에서 승인·거절을 추정하지 않는다. 원문은 기본 제외한다.

## 운영 검증
- 원본과 설치 모듈, 대시보드의 일치를 확인했다.
- 신규 모듈 회귀 37건과 후속 출처 4건·전송 3건, 설치·기존 전송 회귀 8건, 기존 agent_records 34건이 통과했다. 최종 전체 재검증 결과는 PR/MR 본문에 기록한다.
- 운영 Grafana 10개 패널과 Loki의 outcome·intervention·wait·review 저장을 확인했다. 늦은 사건의 원래 시각을 별도 속성으로 보존한다.
- 승인된 이 PC의 연결된 세션만 수집하며 원문 수집은 비활성이다. 재부팅 자동 시작은 설치하지 않았다.
- 사람이 보호 경로 diff를 확인하고 승인하는 절차는 병합 전에 남아 있다.

## 새 세션 자동 연결 독립 리뷰
사용자 요청으로 worktree별 자동 연결 정책을 추가했다. 활성화 이후 생성된 같은 worktree 세션만 등록하고 기존 수동 연결을 잠금 내부에서 보존한다. R1 결함 0건, R2 한글·긴 브랜치 작업 키 누락 1건을 발견해 반영하고 독립 재확인했다. 최종 대상 테스트 결과와 이 PC 운영 활성화 결과는 PR/MR 본문에 기록한다. 다른 worktree 자동 연결과 과거 세션 소급 수집은 이 정책에 포함하지 않는다.
